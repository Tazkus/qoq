# Install quality-of-quantity-protocol in Codex

Use this repository as a Codex plugin/skill source.

## One-click path (recommended)

1. Copy the GitHub repository URL.
2. Paste it directly into Codex chat.
3. Accept the installation prompt shown by Codex.

## Manual fallback

If no prompt appears, tell Codex:

```text
Install the plugin/skill from this repository: https://github.com/Tazkus/qoq
```

Then start a fresh session and verify the skill is available.

## Verify

Ask Codex:

```text
Please apply quality-of-quantity-protocol for this change.
```

If installed correctly, Codex should load and follow the repository skill instructions from `SKILL.md`.
